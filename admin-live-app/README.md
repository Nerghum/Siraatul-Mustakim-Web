# সিরাতুল মুস্তাকিম — অ্যাডমিন লাইভ বয়ান ব্রডকাস্টার অ্যাপ (Admin Live App)

অ্যান্ড্রয়েড ভিত্তিক অ্যাডমিন লাইভ স্ট্রিমিং অ্যাপ্লিকেশন। এই অ্যাপটি ব্যবহার করে অ্যাডমিন সরাসরি মোবাইল থেকে লাইভ বয়ান সম্প্রচার করতে পারবেন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **অ্যাডমিন প্রমাণীকরণ (Authentication)**:
   - অ্যাডমিন ইমেইল ও পাসওয়ার্ড দিয়ে সুরক্ষিত লগইন।
   - টোকেনভিত্তিক সুরক্ষিত এপিআই কল (`JWT Bearer token`)।

2. **লাইভ বয়ান তৈরি (Live Boyan Setup)**:
   - নিয়মিত বয়ানের মতো বিবরণ প্রদান:
     - বয়ান শিরোনাম (Title)
     - ক্যাটাগরি (Category)
     - বক্তা / বয়ানকারী (Author / Speaker)
     - স্থান / জেলা (Location)
     - সংক্ষিপ্ত বিবরণ (Description)

3. **লাইভ মাইক্রোফোন সম্প্রচার (Microphone Live Streaming)**:
   - "Go Live" বাটনে চাপ দিলে মোবাইলের মাইক্রোফোন লাইভ ব্রডকাস্টার হিসেবে কাজ শুরু করে।
   - অডিও স্তর ও ভিইউ মিটার (VU Meter) রিয়েল-টাইম ভিজ্যুয়ালাইজেশন।

4. **হেডফোনে লাইভ মনিটরিং (Headphone Pass-through Monitoring)**:
   - অ্যাডমিন হেডফোন পরলে ফোন থেকেই নিজের কণ্ঠ লাইভ মনিটর করার সুবিধা।
   - হেডফোন মনিটরিং অন/অফ টগল ও মনিটর ভলিউম নিয়ন্ত্রণ।

5. **লাইভ ভলিউম নিয়ন্ত্রণ (Live Volume & Gain Control)**:
   - ব্রডকাস্ট ভলিউম / মাইক্রোফোন গেইন সরাসরি ইউআই থেকে অ্যাডজাস্ট করার অপশন (0% - 100%)।

6. **রিয়েল-টাইম স্টুডিও (Live Studio)**:
   - লাইভ লাল ব্লিঙ্কিং ব্যাজ (🔴 LIVE)।
   - চলমান সময়ের টাইমার (Elapsed Timer)।
   - রিয়েল-টাইম শ্রোতা সংখ্যা (Live Listener Count via VPS WebSocket)।

7. **দ্বিমুখী সংরক্ষণ ব্যবস্থা (Server & Mobile Storage)**:
   - **সার্ভার স্টোরেজ**: লাইভ শেষ হওয়ার পর সম্পূর্ণ লাইভ অডিওটি স্বয়ংক্রিয়ভাবে সার্ভারের `data/boyan/audio/` ফোল্ডারে সংরক্ষিত হয় এবং ডাটাবেজে একটি নতুন বয়ান (`Boyan`) তৈরি হয়।
   - **মোবাইল স্টোরেজ**: সম্পূর্ণ লাইভ অডিও রেকর্ডিংটি তাৎক্ষণিকভাবে সেই মোবাইলের লোকাল স্টোরেজে (`boyan-recordings/live-boyan-[id].m4a`) স্থায়ীভাবে সংরক্ষিত থাকে।

8. **ভিপিএস সিগন্যালিং সার্ভার (VPS Signaling Server)**:
   - নোড.জেএস এবং Socket.io চালিত ভিপিএস সিগন্যালিং সার্ভার।
   - ওয়েবসকেট অডিও ব্রডকাস্ট ও এইচটিটিপি লাইভ চাঙ্ক স্ট্রিমিং (`/api/live/stream/:id`)।

## 🚀 যেভাবে চালাবেন (How to Run)

### ডিপেন্ডেন্সি ইন্সটল
```bash
cd admin-live-app
npm install
```

### লোকাল ডেভেলপমেন্ট
```bash
# অ্যান্ড্রয়েডে চালাতে
npx expo run:android

# অথবা এক্সপো গো দিয়ে ডেভেলপমেন্ট সার্ভার শুরু করতে
npx expo start
```

### পরিবেশ ভেরিয়েবল (.env)
```env
EXPO_PUBLIC_API_BASE_URL=https://siraatul-backend.hcsb.org.bd
```
*(লোকাল টেস্টিংয়ের জন্য `http://<আপনার-পিসি-আইপি>:5001` ব্যবহার করুন)*
